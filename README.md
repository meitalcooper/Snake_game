# Snake Game
Snake Game is a classic arcade game where the player controls a snake that moves around the screen, eats food, and grows longer.
The objective is to score as many points as possible by consuming food without hitting the walls or the snake's own body.


# Features
 - **Simple Controls**: Use the arrow keys to move the snake.
 - **Collision Detection**:
  - The snake grows when it eats food.
  - The game ends when the snake collides with a wall or its own body.
 - **Score Tracking**: The game keeps track of the player's score.

# Game Mechanics
- The snake grows longer each time it eats food.
- The game ends if the snake collides with the screen boundaries or its own tail.


# Technologies Used
- **Python**: Core language used to build the game.
- **Turtle Graphics**: Used for game visuals and animation.
- **OOP**: Implemented to structure the snake, food, and scoreboard in classes.
